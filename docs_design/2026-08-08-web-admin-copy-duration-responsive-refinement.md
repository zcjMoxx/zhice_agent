# Web 管理后台文案、耗时与窄屏布局细化

## 背景

安全审计筛选字段缺少用途说明，Turn 耗时固定显示毫秒，角色权限在主内容区域较窄时出现严重挤压；认证与个人资料中的账号术语也不统一。

## 目标

提高筛选项可理解性，按量级展示耗时单位，修复窄屏 PC 角色布局，并统一账号、密码和昵称文案。

## 范围边界

仅调整 Web 展示与格式化逻辑，不改变审计筛选参数、用户模型字段、权限协议或后端数据结构。

## 模块设计

- 安全审计筛选使用可见标签和简短说明。
- 耗时格式化按毫秒、秒、分钟、小时逐级换算并保留两位小数。
- 角色权限在 1100px 以下改为横向角色选择加单列详情。
- 认证和个人资料展示术语统一为账号、密码、昵称。

## 数据流

现有审计参数和 `duration_ms` 数据保持不变，仅在渲染边界格式化；术语变更不影响提交字段。

## 变更文件

- `web/frontend/src/layouts/AdminLayout.vue`
- `web/frontend/src/layouts/AuthLayout.vue`
- `web/frontend/src/components/SettingsCenter.vue`
- `web/frontend/src/styles/app.css`
- 相关前端测试

## 测试方案

覆盖认证术语、耗时单位格式以及现有组件行为，并运行 lint、typecheck、完整测试和生产构建。

## 验收标准

- 审计筛选字段用途可直接理解。
- 耗时根据量级切换单位并保留两位小数。
- 窄屏 PC 角色标题不再竖排。
- 登录注册和个人资料术语符合统一口径。
