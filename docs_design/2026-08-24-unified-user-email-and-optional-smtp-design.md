# 统一“我的邮箱”与可选 SMTP 代发设计

## 背景

当前产品把“通知邮箱”和“个人邮箱（SMTP）”作为两个独立概念：工作流官方通知要求用户已经拥有已验证的通知邮箱，但设置页只提供个人 SMTP 连接，没有通知邮箱的设置与验证入口。结果是管理员即使已经配置官方 SMTP，普通用户仍无法完成官方通知链路，也容易误以为个人 SMTP 就是通知邮箱。

## 目标

- 用户只理解一个稳定身份：“我的邮箱”。它默认用于接收智策官方通知。
- 官方 SMTP 由工作区统一配置，发件人例如 `notify@zouzhou.xyz`，用户无需配置发信凭据即可接收通知。
- 用户可以在同一邮箱卡片下额外配置 SMTP 授权码，获得“使用我的 SMTP 对外发信”的可选能力。
- 已存在且通过 SMTP 登录验证的个人邮箱，在用户尚无通知邮箱时自动迁移为已验证的“我的邮箱”，不要求重复配置。

## 范围边界

本次包含：通知邮箱状态查询、验证码发送与校验、现有 SMTP 邮箱迁移、设置页统一展示、工作流文案和能力判断、单元测试与前端构建。

本次不包含：收取邮件、IMAP、邮箱联系人、多个通知邮箱切换、组织级邮件地址簿，以及删除 SMTP 时自动删除通知邮箱。

## 模块设计

### 1. 邮箱身份

`user_notification_endpoints` 继续作为用户通知邮箱的唯一事实来源。一个用户最多选择一个默认的、已验证且启用的邮箱作为“我的邮箱”。SMTP 连接仍保存在加密的 `external_connections` 中，只表达可选的发信能力，不再承担独立的用户邮箱概念。

### 2. 验证挑战

认证数据库新增通知邮箱验证码挑战表，保存用户、目标地址、加盐后的验证码摘要、失效时间、尝试次数和消费时间。验证码只通过已配置的官方 SMTP 发送，十分钟失效，成功验证后才把目标地址写成启用的默认通知邮箱。

### 3. SMTP 迁移

用户成功创建个人 SMTP 连接时，如果当前没有已验证通知邮箱，则把通过 SMTP 登录验证的账号地址登记为已验证的“我的邮箱”。列出现有连接时执行同样的幂等回填，以兼容升级前已有数据；已有通知邮箱不被覆盖。

### 4. API

在用户自有邮件连接 API 下增加：

- 查询“我的邮箱”状态；
- 请求发送邮箱验证码；
- 提交验证码完成验证；
- 使用官方 SMTP 向“我的邮箱”发送测试通知。

所有接口只操作当前登录用户，官方测试不接受任意收件人。

### 5. 设置页

“连接与账号”中的邮件区域统一命名为“我的邮箱”：先展示邮箱地址和验证状态，再提供更换/验证与“发送测试通知”。SMTP 区域改为“SMTP 代发（可选）”，说明它只影响工作流使用用户邮箱向其他收件人发信。

### 6. 工作流

发送结果继续保留两种不同能力，但使用面向用户的明确名称：

- “发送到我的邮箱”：官方 SMTP 发送给当前用户已验证的邮箱；
- “使用我的 SMTP 发送”：使用用户选择的 SMTP 连接发送给指定收件人。

## 数据流

```text
设置我的邮箱 -> 官方 SMTP 发送验证码 -> 用户提交验证码
            -> auth.sqlite3 保存已验证通知邮箱
            -> 工作流“发送到我的邮箱”可用

配置 SMTP 授权码 -> 验证 SMTP 登录 -> connections.sqlite3 加密保存
                -> 若尚无我的邮箱则幂等回填
                -> 工作流“使用我的 SMTP 发送”可用
```

## 变更文件

- `agent/auth/schema.py`、`agent/auth/store.py`：验证码挑战和通知邮箱状态。
- `agent/connections/runtime.py`、`agent/app/api/connection_routes.py`、`agent/app/runtime.py`：统一邮箱服务、API 和运行时依赖。
- `web/frontend/src/api/*`、`web/frontend/src/components/SettingsCenter.vue`：我的邮箱和可选 SMTP UI。
- `web/frontend/src/pages/WorkflowPage.vue`：发送方式文案与引导。
- 对应认证、连接、设置页和工作流测试与测试说明。

## 测试方案

- 验证码摘要不保存明文，错误、过期、尝试次数和成功消费路径可控。
- SMTP 新建及已有连接回填只在用户没有已验证邮箱时发生，不覆盖既有选择。
- 官方测试只能发给当前用户已验证邮箱。
- 设置页展示“我的邮箱”和“SMTP 代发（可选）”，工作流展示两个明确发送方式。
- 执行 Python 定向测试、前端 Vitest、TypeScript 构建与生产静态资源构建。

## 验收标准

- 现有 SMTP 用户进入设置页后，其邮箱自动显示为已验证的“我的邮箱”。
- 未配置 SMTP 的用户也能通过官方邮件验证码设置“我的邮箱”。
- 配置 SMTP 与否不影响接收官方通知；没有 SMTP 时仅禁用 SMTP 代发。
- 工作流官方通知不接受任意收件人，SMTP 代发仍要求发送账号、收件人和显式同意。
- 真实 gateway 重启后能力状态、设置页和一封官方测试邮件链路均通过。
