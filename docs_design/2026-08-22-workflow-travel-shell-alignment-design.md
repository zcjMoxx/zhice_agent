# 工作流与旅游规划产品壳统一设计

## 背景

工作流总览虽然沿用了双栏结构，但顶栏缺少“返回聊天”，产品名使用中文和自定义图标；右侧首屏同时出现大号新建入口，与左侧新建重复。最近工作流使用无语义箭头和无文字开关，编辑页又重复放置返回箭头及启停控制。画布、步骤、详情和运行记录连续铺满，缺少旅游规划已有的区域层级。

## 目标

- 总览和编辑共用旅游规划式的单页面产品壳、Logo、英文产品名和顶栏规格。
- 总览提供“返回聊天”，英文产品名可点击回到工作流总览。
- 仅保留左侧一个“新建工作流”入口，首屏说明区缩小。
- 最近工作流取消箭头，使用明确的“打开”和带中文状态的启停操作。
- 左侧工作流列表始终保留，右侧在模板、流程画布和执行记录之间切换。
- 编辑区不显示返回箭头和启停开关，启停统一在左侧列表管理。
- 运行历史不再固定占用底部空间，作为右侧独立视图按需显示。

## 范围边界

- 不改变工作流创建、保存、发布、运行、暂停、恢复和删除接口。
- 不改变画布节点、连线、调度和运行历史的数据结构。
- 不执行工作流，不发送外部消息。

## 模块设计

### 产品顶栏

工作流产品名固定为 `ZhiCe Workflow`。总览左侧品牌和右侧“返回聊天”都可回到主聊天，右侧同时保留快捷设置；编辑页左侧品牌在保存当前草稿后回总览。

### 总览操作

新建入口只保留在左侧“最近编辑”区域。左侧列表在模板总览和工作流编辑时始终存在；列表项默认透明，仅在悬停或选中时出现浅色背景。整行点击打开工作流，副标题直接显示中文状态和下次运行时间，右侧只保留明确的开启/关闭文字操作与删除。

总览不再使用宣传页式的大字号标题。主标题、分区标题和卡片高度统一收敛到旅游规划工作区的内容尺度，让模板是右侧工作区的一种视图，而不是另起一层首页。

### 编辑区域

步骤栏、画布和节点详情保留现有功能。右侧顶部提供“模板 / 流程画布 / 执行记录”切换，画布默认占满可用高度，节点详情仍可收起；执行记录替换右侧内容而不是固定在页面底部。URL 继续保留 `/workflows/:workflowId`，用于刷新恢复和直接打开，但视觉上不再进入另一套子页面。
