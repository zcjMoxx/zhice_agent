# 工作流导航、操作区与时间选择统一设计

## 背景

工作流编辑页顶部同时出现返回箭头、房子、对话、删除、保存、发布和立即运行，导航与业务操作混在一起；“工作流编辑”小字和工作流名称挤在同一区域，标题缺少清晰层级。总览页虽然显示状态文字，但不能直接启停工作流。定时节点仍使用浏览器原生时间输入，与后台已经使用的日期时间选择器风格不一致。

## 目标

- 编辑页只保留一个“全部工作流”返回入口，不再出现房子或“对话”。
- 工作流名称作为页面主标题，可编辑但视觉上仍像标题。
- 顶部常驻操作精简为保存、发布、运行；删除收进“更多”菜单。
- 总览页的最近工作流和全部工作流卡片都能直接查看并切换启停状态。
- 定时节点复用后台 `DateTimePicker` 的视觉与交互，支持纯时间和日期时间两种模式。

## 范围边界

- 不改变保存、发布、立即运行、删除、暂停和恢复的后端接口。
- 总览启停仅对已经发布且状态为开启或关闭的工作流可用；草稿显示“未开启”。
- 不改变调度表达式生成逻辑，只替换用户选择时间的交互组件。
- 不运行工作流，不发送 QQ 消息。

## 模块设计

### 编辑页导航与标题

左侧使用单一返回箭头和“全部工作流”文字。工作流名称使用带焦点态的标题输入框，不再展示“工作流编辑”技术标签。

### 顶部操作

常驻按钮为“保存”“发布”“运行”。删除属于低频危险操作，放入省略号“更多”菜单并保留二次确认。启停开关作为状态控制，与编辑操作分区显示。

### 总览启停

已发布工作流显示小型开关：绿色为已开启，灰色为已关闭。点击直接调用暂停或恢复接口并刷新列表。草稿只显示“未开启”，不伪装成可用开关。

### 时间选择

扩展 `DateTimePicker`：

- `datetime` 模式保持后台审计筛选现有行为；
- `time` 模式只展示统一的小时、分钟面板并返回 `HH:mm`；
- 每天、每周、每月定时使用 `time` 模式；
- 单次执行使用 `datetime` 模式。

## 数据流

```text
总览开关 -> 暂停/恢复接口 -> 刷新工作流状态
时间选择器 -> time_of_day/run_at -> 现有调度规则生成 -> 保存/发布
```

## 测试方案

- 验证日期时间模式保持原行为。
- 验证纯时间模式打开后不显示日历并返回 `HH:mm`。
- 运行完整前端测试、ESLint、类型检查和生产构建。
- 使用应用内页面检查编辑页顶栏、总览状态和时间选择器视觉。
- 只读核对真实天气工作流状态与调度未被测试改变。

## 验收标准

- 顶栏没有“对话”、房子图标和重复导航图标。
- 标题清晰，右侧常驻按钮数量明显减少。
- 总览无需进入画布即可判断和切换工作流是否启用。
- 定时节点使用与后台一致的时间选择器。
