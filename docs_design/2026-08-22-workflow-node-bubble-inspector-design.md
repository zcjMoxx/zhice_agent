# 工作流节点气泡配置窗口设计

## 背景

节点类型已经移到画布顶部，但节点配置仍以独立右栏呈现。打开节点详情后，画布再次被压缩，配置窗口与所选节点的空间关系也不直观。

## 目标

- 彻底取消节点详情右栏，画布始终使用完整宽度。
- 点击节点后，在节点旁边弹出气泡式配置窗口。
- 拖动画布、缩放或移动节点时，气泡跟随当前节点重新定位。
- 保留现有全部配置、测试查询、删除节点和关闭详情能力。

## 范围边界

- 不修改节点配置字段、工作流数据结构、保存、发布和运行逻辑。
- 不引入新的前端依赖。
- 不运行工作流，不发送外部消息。

## 模块设计

### 定位规则

气泡优先显示在节点右侧；右侧空间不足时显示在左侧；左右都不足时显示在节点下方。定位使用节点和画布的实际渲染矩形计算，气泡始终限制在画布可见范围内。

画布移动、缩放、节点拖动、窗口缩放和选中节点变化都会触发下一帧重新定位，避免在连续交互中频繁同步布局。

### 视觉与交互

气泡由定位外壳、指向节点的小箭头和内部可滚动配置区组成。气泡宽度保持紧凑，最大高度受当前画布剩余空间限制。点击关闭后仅隐藏气泡，不改变节点；点击节点或顶部对应步骤可重新打开。

### 画布布局

编辑主体只保留“顶部步骤按钮条 + 完整宽度画布”。节点气泡绝对定位在画布内部，不参与网格列宽计算，因此不会压缩画布。

## 测试方案

- 运行前端 ESLint、TypeScript、完整 Vitest 和生产构建。
- 在真实页面验证气泡的打开、关闭、左右翻转、画布移动跟随和节点拖动跟随。
- 确认执行记录数量和工作流状态未变化，且没有发送外部消息。

## 验收标准

- 页面不存在独立节点详情右栏。
- 打开详情后画布宽度不变化。
- 气泡贴近所选节点且不会超出画布边界。
- 拖动画布或节点后，气泡仍跟随所选节点。
