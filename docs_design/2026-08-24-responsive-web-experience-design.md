# 2026-08-24 手机与窄窗口响应式体验优化设计

> 说明：工作流手机画布的后续固定 viewport、手势平移与操作区精简采用 2026-08-25 方案，参见 `docs_design/2026-08-25-mobile-workflow-canvas-interaction-design.md`；本文保留 8 月 24 日的整体响应式方案背景。

## 背景

当前 Web 前端已经包含若干响应式断点，但真实 Chrome 以 390×844 viewport 验证后，仍发现“没有文档级横向滚动、内容却被固定栏位挤窄”的问题：旅游页在手机宽度继续保留 220px 计划侧栏，导致主内容标题逐字换行；工作流列表的模板区域继续使用多列卡片，首张卡只展示约半宽。管理页顶部栏目通过横向滚动承载，但缺少统一的触控滚动和边缘约束。工作流画布、节点详情与运行记录还需要在窄屏上从桌面并排结构切换为可操作的单列结构。

## 目标

- 手机浏览器与 PC 非全屏/窄窗口下不出现非预期横向溢出、内容裁切或文字被挤成竖排。
- 聊天、设置、旅游规划、工作流列表/画布/节点详情/执行记录、管理页和认证页的核心操作可见、可滚动、可触控。
- 弹层限制在动态 viewport 内，长文本、表单和操作按钮允许换行或内部滚动。
- 保持桌面宽屏现有信息密度和业务行为不变。

## 范围边界

- 只调整 Vue 前端布局样式、必要的 viewport 状态与相应单元测试，不改变 API、Session、Workflow 或 Travel 业务语义。
- 断点以现有 720/760px 体系为主；窄桌面在 761–1120px 范围保留紧凑双栏或折叠布局。
- 横向滚动只用于确实需要保留顺序的导航、标签和进度轨道；正文和表单不依赖页面级横向滚动。

## 模块设计

### 全局、聊天、设置、认证与管理

- 为可滚动导航增加触控惯性、滚动条隐藏和稳定的最小触控高度。
- 为窄屏 header/actions、长文本、详情定义列表和弹层补充 `min-width: 0`、换行及动态 viewport 高度约束。
- 设置中心手机态保持全屏单列，顶部栏目横向滚动，详情区独立纵向滚动。

### 旅游规划

- 手机态将计划侧栏改为不占主内容宽度的抽屉式覆盖层；收起时完全移出视口，仅保留明确的展开入口。
- 主结果区占满 viewport，表单详情和来源抽屉限制在安全区域内。
- 操作区、卡片 header、路线与长文本在小屏换行，触控按钮保持至少 40–44px 可点击区域。
- 交通摘要和逐段公交/步行信息在手机态改为单列堆叠，不保留桌面的第 2 列定位，避免长站名被压成逐字竖排。

### 工作流

- 手机态将工作流侧栏改为抽屉式覆盖层，列表与编辑区始终占满宽度。
- 模板卡、工作流卡和运行记录改为单列；画布工具栏、节点栏允许横向触控滚动。
- 节点详情气泡在手机态固定为底部 sheet，限制最大高度并允许内部滚动，避免超出 viewport。
- 编辑器 toolbar/actions 可换行，画布保留足够高度，运行列表与详情按单列排列。
- 画布浮动工具栏中的按钮禁止收缩和文字换行；手机态“自动布局”使用带 title 的 40px 图标按钮，避免中文被压成竖排。
- 移动端从 Session、旅行计划或工作流抽屉选择条目后立即收起抽屉，让新打开的内容直接可见。
- 连线增删、画布缩放、配置提示、节点编辑和执行结果复制等高频操作提供至少约 40px 的触控目标；节点编辑入口在触摸设备上常显。
- 手机态编辑器使用固定 viewport 网格：工具栏压缩为单行横向操作区，画布占满剩余高度，外层不做整页纵向滚动；Vue Flow 的 `height: 100%` 因此能解析为非零高度，节点真实绘制且触控拖动画布不会被外层滚动抢占。
- 配置提示在画布内压缩成单行横向滚动条，保留问题入口但不再用大卡片遮住节点。

## 数据流

响应式变化只由 CSS media query 和现有 sidebar collapse 状态驱动。用户点击侧栏展开/收起、节点或运行记录后，仍走现有 Vue 状态与 API 数据流；布局层只改变呈现方式和滚动容器。

## 测试方案

- 扩展 CSS/组件单元测试，锁定手机侧栏抽屉、单列模板、底部节点详情和弹层 viewport 约束。
- 执行 `npm run test`、`npm run typecheck`、`npm run lint`、`npm run build`。
- 使用真实 Chrome CDP 分别以 390×844 手机 viewport 和约 800×700 窄桌面 viewport 验收主要路由；检查 `documentElement.scrollWidth/clientWidth`、越界元素与截图。

## 验收标准

- 重点页面无非预期文档级横向溢出，正文不被侧栏压窄或裁切。
- 手机态旅游和工作流主区域占满宽度，侧栏可覆盖展开并可收起。
- 工作流节点详情、来源/表单/设置/日期等弹层均不超出动态 viewport。
- 核心按钮、输入和导航触控目标不小于约 40px，长文本可正常换行。
- 从任一移动端抽屉选择内容后，抽屉自动收起且不会继续遮挡主内容。
- 前端全量测试、typecheck、lint 和生产 build 全部通过。
