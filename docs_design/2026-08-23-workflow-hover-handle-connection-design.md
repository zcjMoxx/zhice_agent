# 工作流悬停连接点交互设计

## 背景

已落地的“两步式连接”在节点内部常驻“连接下一步 / 连接是 / 连接否”按钮，增加了节点视觉负担，也把连线变成额外的模式切换。节点容器还在 `pointerdown` 时打开详情，导致用户操作连接点时先弹出节点配置气泡。

## 目标

- 删除节点内部的连接按钮和两步式目标选择状态。
- 鼠标悬停节点或节点被选中时显示连接点。
- 用户可以点一下来源连接点进入连线状态，再点击目标连接点完成连线；也可以按住来源连接点直接拖到目标连接点。
- 点击空白画布取消尚未完成的连线，不打开快速新增菜单。
- 操作连接点时不打开节点详情气泡。
- 条件节点继续用独立的“是 / 否”连接点表达分支。

## 范围边界

本次只调整工作流画布前端交互和样式，不改变工作流协议、运行时、权限、调度或后端接口。连线中途落在画布空白处不再打开快速新增菜单；既有连线中间的显式“插入节点”入口继续保留。

## 模块设计

### 节点与详情

节点详情只由 Vue Flow 的节点点击事件或编辑按钮打开。节点根元素不再在 `pointerdown` 阶段选中节点，避免 Handle 操作被提前解释成节点点击。

### 连接点

普通节点使用左侧输入点和右侧输出点；开始节点只有输出点；条件节点保留右侧“是 / 否”两个输出点。连接点默认透明，在节点悬停、选中或键盘聚焦时放大显示。Handle 自身阻止指针和点击事件继续冒泡，但不阻断 Vue Flow 在 Handle 上注册的连线逻辑。

点击来源连接点后，画布进入可感知的连线状态：来源点持续放大并发光，所有连接点保持可见，画布、节点和连接点上的鼠标统一显示十字连线光标。连接成功、目标无效或点击空白取消后恢复普通光标。

点击连线模式额外渲染一条不接管事件的 SVG 贝塞尔预览线，从来源连接点中心持续跟随鼠标。空白画布使用张开手光标、拖动画布使用握紧手光标，节点主体使用手指 `pointer` 光标。连接点的实际 DOM 尺寸同步增大，以同时扩大视觉圆点和点击命中区域。

### 连线校验

`workflowConnectionIssue` 继续统一校验自连接、重复连接、开始节点作为目标、条件分支占用和循环。非法拖拽只显示校验反馈，不恢复两步式连接状态。

## 数据流

```text
悬停节点 -> 显示 Handle -> 点击来源 Handle -> 点击目标 Handle
                         \-> 或按住并拖到目标 Handle
          -> Vue Flow connect -> 前端校验 -> 写入 edge
```

Handle 的指针与点击事件停止冒泡，因此不会进入节点点击事件，也不会打开详情气泡。

## 测试方案

- 页面测试确认节点中不再出现连接按钮。
- 页面测试确认操作连接点不会打开节点详情。
- 页面测试确认连接点落在空白画布时不打开快速新增菜单。
- 页面测试确认点击空白画布会结束未完成的点击连线状态。
- 页面测试确认点击连线状态在画布 DOM 上持续暴露，供光标和连接点高亮样式使用。
- 页面测试确认点击连线时预览线出现、随鼠标坐标更新，并在取消后消失。
- 页面测试通过 Vue Flow `connect` 事件覆盖普通输出与条件分支连线。
- 运行前端类型检查、定向测试和生产构建。

## 验收标准

- 节点内不再显示“连接下一步 / 连接是 / 连接否”。
- 悬停节点时连接点清晰可见，可点击两端或直接拖拽连接现有节点。
- 连接点落空时不弹出“添加节点”，点击空白画布会取消连线状态。
- 点击来源连接点后，鼠标持续显示十字连线形态，来源点持续高亮，直到连接结束或取消。
- 点击或拖动连接点不会弹出节点详情气泡。
- 点击节点主体仍可打开详情。
- 条件分支语义和既有连线校验保持不变。
