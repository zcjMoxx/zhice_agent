# 工作流返回恢复、发送结果默认值与邮箱防刷补丁设计

## 背景

云端 `owner` 已完成微信绑定并建立过微信会话，但工作流编辑页只在首次挂载时读取一次通知能力。用户在微信完成首次对话后返回页面，微信选项仍可能保持禁用，设置中心还会直接展示 `active` 等微信内部状态值，与 QQ 的中文状态不一致。另一方面，工作流编辑组件离开后重新挂载时，Pinia 中可能仍保留同一工作流；现有监听仅在 `workflow_id` 变化时水合画布，因此本地节点数组会暂时为空，直到刷新页面重新请求详情。入门模板还会在 QQ 可用时自动把“发送结果”改为 QQ 通知，与用户期望的安全默认值不一致。设置中心的邮箱验证码接口目前也没有重发冷却，页面只能阻止请求进行中的重复点击，无法抵御刷新、多标签页或直接调用接口造成的邮件轰炸。

## 目标

- 微信不可用时明确提示“先绑定、再完成一次微信对话”的完整前置步骤。
- 页面重新聚焦、从后台恢复或关闭连接设置后，自动刷新通知能力。
- 微信连接状态统一显示为本地化用户文案，不暴露内部状态码。
- 从聊天页返回已保存工作流时立即恢复全部节点，不依赖手动刷新。
- 所有入门模板的“发送结果”默认仅保存到执行记录，不自动选择 QQ、微信或邮件。
- 邮箱验证码按账号强制 60 秒重发冷却，并在前端显示剩余秒数。

## 范围边界

- 调整前端工作流编辑状态、水合时机、能力刷新、模板默认值，以及邮箱验证码的前后端冷却控制。
- 不改变微信绑定协议、主动消息发送约束、后端工作流格式或既有已保存工作流。
- 不自动替用户开启外部通知；用户仍需主动选择渠道并确认发送授权。
- 邮箱限制按登录用户执行，不按邮箱地址或浏览器实例执行；不引入验证码日配额、IP 限流或新的外部限流服务。

## 模块设计

### 微信引导与刷新

工作流页在微信能力不可用时展示统一的两步引导，并保留进入“连接与账号”的入口。页面在窗口重新获得焦点、文档重新可见、连接设置关闭后重新读取工作流能力；关闭连接设置时同时刷新邮件连接。设置中心把 `active`、`unbound`、`reconnect_required`、`reconnecting`、`degraded` 等状态映射为中文或英文用户文案，未知值也不直接透出内部枚举。

### 画布重新水合

将当前工作流监听改为首次挂载立即执行。这样即使 Pinia 中的 `current.workflow_id` 没有变化，新组件实例也会从已保存详情构造本地 `nodes` 与 `edges`。保存同一工作流时仍不会因详情对象更新而重置正在编辑的画布。

### 安全默认发送方式

入门模板的结果节点固定实例化为普通 `template` 节点，权限只声明 `workflow.use`。通知渠道能力只影响用户后续手动选择，不再影响模板初始定义。

### 邮箱验证码重发冷却

认证存储在同一个 SQLite 写事务中读取用户最近一次验证码创建时间并决定是否插入新挑战，避免并发请求同时绕过检查。60 秒内重复请求返回稳定错误码、HTTP 429 和 `retry_after_seconds`；成功响应也返回同一字段。设置中心以服务端秒数启动倒计时，倒计时期间禁用发送按钮并显示“多少秒后可重发”，组件卸载时清理计时器。前端仅负责反馈，后端事务限制才是防刷边界。

## 数据流

1. 进入或返回工作流详情。
2. 立即从 `store.current` 水合画布；若详情尚未加载，再在 `workflow_id` 首次变化时水合。
3. 拉取工作流能力并据此启用通知选项或展示微信前置引导。
4. 用户完成微信绑定和首次对话后返回浏览器，焦点/可见性事件触发能力重查。
5. 新建模板时结果节点保持“仅作记录”，用户手动选择通知后才改变节点类型并产生发送权限。
6. 请求邮箱验证码时，存储层原子检查最近挑战；允许发送则返回 60 秒冷却，被拦截则返回实际剩余秒数。
7. 前端根据成功响应或 429 错误详情恢复倒计时，冷却结束后重新开放按钮。

## 测试方案

- 组件测试覆盖已有 `store.current` 时首次挂载立即显示节点。
- 组件测试覆盖微信不可用引导，以及窗口重新聚焦后能力恢复、选项自动启用。
- 设置中心测试覆盖微信 `active` 显示为“已连接”。
- 模板测试覆盖 QQ 可用时仍默认“仅作记录”且不申请通知权限。
- 存储测试覆盖同一用户冷却内被拒绝、冷却后允许以及不同用户互不影响。
- 运行时与 API 测试覆盖稳定错误码、HTTP 429 和剩余秒数详情。
- 设置中心测试覆盖成功后的倒计时、按钮禁用和服务端 429 后恢复倒计时。
- 运行前端测试、typecheck、lint 和生产构建。
- 使用真实浏览器验证工作流到聊天再返回、微信提示与模板默认结果去向。

## 验收标准

- 已保存工作流往返聊天页面后无需刷新即可看到节点。
- 微信通知不可选时能看到先绑定、再对话的明确提示。
- 完成微信对话后返回页面，能力能够自动刷新。
- 微信卡片不再显示 `active` 等内部状态码。
- 新建天气或摘要模板时，“发送结果”初始值为“仅作记录”。
- 邮箱验证码发送后显示 60 秒倒计时，冷却期内无论页面操作还是直接调用接口都无法再次发送。
