# 工作流连线拖动与移动端边操作修正

> 说明：本记录承接 `2026-08-25-workflow-canvas-connection-followup-design.md`。上一轮解决了预览坐标、边对比和取消手势；本轮修正连线模式拖动语义以及移动端边操作区被画布缩放和视口裁切的问题。

> 追加：移动端连接点的视觉尺寸不能直接作为 Vue Flow 几何尺寸，否则边端点会落在圆心内侧；现改为 18px 几何连接点 + 56px 透明触控扩展，并移除常驻“连线”文字。

> 追加：左右连接点强制以节点外框 50% 高度定位，避免节点底部编辑区的 padding 影响连接点位置，确保连线在两个连接点中心之间，不被卡片内容遮挡。

> 追加：桌面端连接点改为默认常显；Alt+滚轮横向平移不再按 viewport 尺寸禁用，窄桌面和移动仿真均可使用。

> 追加：连线中点移动端入口改为可见小铅笔；空白画布点击会结束连线并清除预览，移动端双击空白沿用取消逻辑；PC 连线模式使用铅笔+连接线光标。

> 追加：按最终交互确认，铅笔入口位于连线几何中点；空白单击仅清除虚拟预览并保留连线模式，双击才取消；PC 自定义连接器光标已实际加入画布样式。

## 背景

真实 390px viewport 验证发现，点击源端口进入持续连线模式后，拖动空白 pane 仍触发 `pan-on-drag`，导致用户想移动连线终点时画布一起移动。已连接边默认交互路径为 20 CSS px，在当前 0.72 缩放下实际只有约 14px；边中点操作按钮位于 Vue Flow 缩放层内，选中后从 x=320 延伸到 x=409，删除按钮被手机视口裁切，因此插入和删除表现为无响应。

## 目标

- 持续连线模式下拖动只移动预览连线终点，不平移画布。
- 从源端口按住拖动时继续使用 Vue Flow 原生拖线，不触发节点或画布拖动。
- 移动端已连接边提供约 40px 的实际触控命中宽度，并在边上方提供不被节点或端口遮挡的明确“连线”选择入口。
- 选中边后，在画布缩放层外展示固定的“插入节点 / 删除连线”操作条；菜单和按钮均不超出视口。

## 范围边界

- 不改变工作流边数据结构、连接校验、撤销历史以及保存发布语义。
- 桌面端保留边中点快捷按钮；固定操作条仅在移动端显示。
- 点击连线模式仍允许使用滚轮、方向控件或取消后拖动画布，不恢复连线模式内的空白拖拽平移。

## 模块设计

### 连线模式拖动

将 Vue Flow 的 `pan-on-drag` 绑定为 `!clickConnectionActive`。点击源端口后，section 的 pointermove 只更新自定义预览终点；退出连线后恢复空白拖动画布。Handle 保留 Vue Flow 自身的 mousedown/touchstart 连接处理。

### 移动端边选择

BaseEdge 的 `interactionWidth` 提升到 56 CSS px，在默认缩放下形成约 40px 的实际命中区。视觉 path 线宽保持不变。考虑到相邻节点与 56px 端口可能覆盖整段短边，移动端另外在边中点上方 72px 渲染 60px 触控范围的“连线”选择入口，使删除不再依赖点击被节点遮挡的 SVG path。

### 移动端边操作条

在 Vue Flow 外层按 `selectedEdgeId` 渲染独立操作条，提供带文字的“插入节点”和“删除连线”按钮。桌面继续使用边中点按钮；移动端隐藏缩放层内的 `.edge-actions`。新增节点菜单在移动端改为视口底部面板，插入位置取所选边两端节点位置的中点。

## 数据流

1. 点击端口进入连接状态，`panOnDrag=false`，pointermove 更新连线终点。
2. 点击已连接边的扩大交互路径，或点击边上方明确的“连线”入口，写入 `selectedEdgeId`。
3. 移动端操作条根据 `selectedEdgeId` 打开插入菜单或调用 `deleteEdge`。
4. 插入完成或删除后清空边选择与操作面板。

## 验收标准

- 连线模式拖动空白 pane 时节点屏幕坐标不变，预览终点随指针变化。
- 移动端边交互路径实际命中宽度约 40px；短边被节点和端口覆盖时，仍可通过边上方的“连线”入口单次触控选中。
- 插入与删除按钮完整位于 390px 视口内，点击后分别出现菜单和删除当前边。
- 桌面端原有边操作和退出连线方式不回归。
