# ZhiCe-Agent 雾银暗色曜石配色设计

> 文档类型：日期设计记录
>
> 归属：Part 16 Web 产品体验与 Vue 前端工程
>
> 承接：`docs_design/2026-07-27-light-obsidian-palette-alignment-design.md`

## 1. 背景

当前暗色主题以接近纯黑的 `#15171a` 为主背景，结构面之间亮度接近，焦点色偏蓝，登录页又继续使用浅色主题的黄绿色环境光。实际效果只是把页面整体压黑，没有形成浅色曜石“近白底、雾灰玻璃、石墨强调”的对应暗色体系。

用户从三套暗色 Demo 中确认 A“雾银曜石”：中性炭灰底、雾银石墨结构面、柔白正文和低透明银灰强调，不使用大面积纯黑或蓝色视觉中心。

## 2. 目标

- 暗色主题成为浅色曜石的语义对应版本，而非简单黑色反相。
- 页面底色、结构面、玻璃面和抬升面保持可辨认但克制的层级。
- 登录、聊天、设置和管理后台消费同一套雾银 token。
- 暗色环境光、品牌面板、Hero、头像和主题缩略图同步收敛。
- 不改变浅色主题、组件结构或任何业务行为。

## 3. 范围边界

- 仅修改 CSS token、共享样式、主题预览、设计文档和 production build。
- 不修改主题偏好持久化、路由、Session、Auth、RBAC、Channel 或 AgentLoop。
- 不引入新的主题名称；仍使用现有 `dark` 值和“暗色曜石”用户文案。

## 4. Token 对应

| 语义 | 浅色曜石 | 雾银暗色曜石 |
|---|---|---|
| 页面底色 | `#fcfbf7` | `#202326` |
| 次级底色 | `#f5f5f1` | `#292d30` |
| 玻璃面 | 近白半透明 | `rgba(58,62,66,.72)` |
| 实体内容面 | `#fcfbf7` | `#2d3134` |
| 抬升面 | `#f9f8f4` | `#34383c` |
| 侧栏 | `rgba(243,243,239,.92)` | `rgba(49,53,57,.90)` |
| 主文字 | `#5c6a72` | `#dce1e2` |
| 次级文字 | `#7d888b` | `#a2abad` |
| 主强调 | `#5c6a72` | `#d7dcdd` |
| 焦点 | 灰绿石墨 | 雾银灰 `#b5c0c2` |

暗色阴影仍允许使用低透明深色以表达高度，但页面和结构面不使用纯黑。环境光改为低透明银灰，登录品牌面板和后台 Hero 使用同一中性石墨渐变。Windows 实际页面审核发现过亮柔白配合全局灰阶字体平滑会让中文笔画出现泛光感，因此主文字从 Demo 初值 `#eef0f0` 收敛为 `#dce1e2`，次级文字收敛为 `#a2abad`，暗色模式恢复系统字体平滑。

## 6. 测试方案

- 运行前端 lint、typecheck、Vitest 和 production build。
- 验证暗色 token 实际写入 `document.documentElement[data-theme=dark]` 后可被浏览器解析。
- 检查登录、聊天、设置和管理后台不出现大面积纯黑及残留蓝色焦点。
- 检查浅色 token 未被暗色调整覆盖。

## 7. 验收标准

1. 暗色主背景为炭灰而非接近纯黑。
2. 侧栏、玻璃面、实体面和抬升面具有稳定层级。
3. 主强调与焦点为中性雾银，不形成品牌蓝视觉中心。
4. 登录页环境光、品牌面板、Hero、头像和主题缩略图与雾银体系一致。
5. 浅色曜石效果保持不变，所有前端验证通过。
