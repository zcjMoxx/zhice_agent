# 工作流画布连线与缩放交互修正

## 背景

移动端画布交互优化落地后，真实桌面与浏览器仿真继续暴露三类问题：点击连线的预览虚线仅在开始时记录源端口坐标，平移后不再贴合端口；已连接边与背景对比不足；`Ctrl + 滚轮` 仅依赖 Vue Flow 对 pinch 的识别，部分鼠标和浏览器状态下不会缩放。此外，持续连线模式需要更快捷但不易误触的退出方式。

## 目标

- 连线预览在画布平移、节点移动和指针移动时始终从当前源端口中心出发。
- 已连接边在明暗主题下都具备清晰、稳定的对比度。
- PC 端 `Ctrl/Command + 滚轮` 由页面稳定处理，以鼠标所在位置为中心缩放；保留 `Alt + 滚轮` 横移。
- 连线模式下，右键空白画布或双击空白画布可以取消，节点、端口和按钮上的右键或双击不误取消。

## 范围边界

- 仅调整工作流画布前端交互、样式和测试，不改变工作流节点、边的数据结构及保存、发布、执行语义。
- 移动端不展示桌面组合键提示；移动端原有拖动、双指缩放和显式取消继续保留。
- 不接管浏览器在画布外部的 `Ctrl + 滚轮` 或右键行为。

## 模块设计

### 连线预览坐标

根据当前 `clickConnectionSource` 在画布 DOM 中查找对应 source Handle，每次指针移动、viewport move 或节点拖动时重新读取端口中心，并换算为画布局部坐标。预览终点继续使用指针相对画布的位置。

### 滚轮缩放

在画布捕获阶段优先识别 `Ctrl/Meta + 滚轮`，阻止浏览器页面缩放和 Vue Flow 重复处理。缩放值限制在现有 `0.25–1.5`，并根据指针相对画布的位置同步调整 viewport x/y，使指针下的流程坐标保持不变。`Alt + 滚轮` 继续只执行横移，普通滚轮透传给 Vue Flow。

### 取消手势

画布 section 在捕获阶段监听 `contextmenu` 和 `dblclick`，避免 Vue Flow 先将双击消费为缩放。仅当事件来自 `.vue-flow__pane` 内且不属于节点、端口、边操作区时取消当前点击连线；右键取消时阻止原生菜单，双击取消时阻止后续画布默认动作。

### 已连接边

为普通 edge path 设置更高对比度的主题混合色、稳定线宽和透明度；选中边继续使用强调色和更粗线宽。

## 数据流

1. 点击源端口写入 `clickConnectionSource` 并建立预览。
2. 指针、viewport 或节点位置变化触发源端口坐标同步。
3. 点击目标完成连线；右键/双击空白、再次点击源端口、取消按钮或 Escape 清空连接状态。
4. `Ctrl/Meta + wheel` 计算目标 zoom 和以指针为锚点的新 viewport，`Alt + wheel` 仅更新 viewport x。

## 测试方案

- 单元测试覆盖预览源点同步、右键/双击空白取消、非空白不取消、Ctrl/Meta 缩放事件拦截、Alt 横移和普通滚轮透传。
- 响应式契约测试锁定桌面提示、滚轮捕获入口和边样式。
- 运行前端全量测试、typecheck、lint 与生产 build。
- 使用真实手机与窄桌面 viewport 验证端口、拖动、预览贴合、边对比和取消手势。

## 验收标准

- 平移画布后，预览虚线起点仍与当前源端口中心重合，误差不超过 1px。
- 普通已连接边在真实页面中清晰可辨，选中态区别明确。
- PC 画布内 `Ctrl/Command + 滚轮` 无需刷新即可缩放，缩放中心跟随鼠标；`Alt + 滚轮` 横移不产生纵移。
- 连线模式下右键或双击空白立即退出，节点和操作按钮交互不误退出。
