# Web 安全审计日期时间选择组件交互细化

## 背景

首版站内组件缺少快捷年月选择，底部取消和清除的语义不够清晰，且开始、结束时间之间没有前端约束。

## 目标

提供年月切换、明确关闭与重置语义，并保证结束时间不早于开始时间。

## 范围边界

仅细化安全审计日期时间组件及其筛选状态联动，不改变后端接口和审计查询语义。

## 模块设计

月历标题作为年月面板入口；右上角关闭按钮放弃临时修改；“不限制”清空筛选；“恢复当前时间”只重置临时值；结束时间通过 `minValue` 接收开始时间下限。

## 数据流

开始时间变化后，若现有结束时间更早则同步到开始时间。结束时间组件禁用更早日期，并在时分早于下限时禁止确定。

## 测试方案

覆盖年月面板切换、时分选择、明确确定操作和结束时间下限约束，并运行前端完整检查。

## 验收标准

- 点击年月标题可选择年份和月份。
- 右上角叉可关闭且不保存临时值。
- 不限制和恢复当前时间语义明确。
- 结束时间不能早于开始时间。
