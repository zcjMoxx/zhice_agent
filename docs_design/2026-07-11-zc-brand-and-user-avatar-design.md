# ZC 品牌标识与用户头像区分设计

## 背景

产品标识和用户头像此前共用深色方形、青色点缀的视觉语言。当用户名以 `Z` 开头时，用户入口的首字母头像容易和产品标识混淆。第一版在旧 Z 形路径上附加小号 `ZC` 文字，实际视觉仍会先读成 Z；浅蓝首字母圆形也不够稳定。

## 目标

1. 产品标识使用用户选定的 A 版 `ZC` 星芒图形。
2. 用户头像采用用户选定的 C 版交叠结构与 F 版白底深蓝配色，显示用户名前两个字符。
3. 通过图形、形状和颜色区分产品与用户。

## 范围边界

- 不改变 favicon、用户名或显示名。
- 不引入图片上传、自定义头像或后端资料字段。

## 模块设计

- `web/static/zhice-logo-a.png`：由用户选定的 A 版视觉稿生成，作为页面和 favicon 的统一产品资产。
- `index.html`：登录页和侧边栏引用同一 Logo PNG。
- `gateway.py`：favicon 路由返回同一 Logo PNG。
- `app.js`：从用户名按 Unicode 字符取前两个字符并更新头像；单字符用户名自动隐藏第二字符。
- `styles.css`：用户头像使用白底、深蓝圆框和交叠的衬线斜体双字母，与深色产品 Logo 成套但不相似。
- 静态 CSS 版本更新，保证浏览器立即获取样式。

## 测试方案

| 用例 | 预期 |
| --- | --- |
| 产品 Logo | 登录页、侧边栏和 favicon 使用同一 A 版资产 |
| 用户头像 | 普通用户名显示前两个大写字符；单字符用户名只显示一个字符 |
| 回归 | 不再保留旧的 `logo-avatar` 样式 |

## 验收标准

1. 产品 Logo 与用户选定的 A 版视觉一致。
2. 用户头像符合 C 结构 + F 配色，并与产品 Logo 一眼可分。
3. 静态测试、Ruff 和 JS 语法检查通过。
