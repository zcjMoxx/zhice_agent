> 说明：本文记录浅色曜石确认过程；暗色主题后续已收敛为雾银曜石，应参考 `docs_design/2026-07-28-mist-silver-dark-obsidian-design.md`。本文其余正文保持当时方案原貌。

## 1. 背景

Part 16 已完成 Vue 落地和第一轮聊天布局修正，但实际页面仍把浅色主题表现成了“冷灰画布 + 蓝色品牌标记 + 半屏深石墨登录面板”。随后第一次审核又错误地把它改成纯白冷灰。两者都与最终确认的曜石方向不一致。

本次以用户最终确认的四张登录、聊天、设置和管理后台截图为唯一浅色基准：暖米白底、雾灰玻璃、灰蓝石墨强调，并在登录页使用克制的浅青绿色环境光。蓝色不作为品牌主色。原有深石墨视觉仅属于暗色曜石主题。

## 2. 目标

- 登录、聊天、设置与管理后台共享同一套暖色明亮曜石语义 token。
- 浅色登录页使用雾灰品牌面板和暖米白到浅青绿的表单面板，不使用纯黑。
- 品牌标记在产品界面中中性化，不再形成蓝色视觉中心。
- 当前 Session、用户气泡、hover 和主操作统一使用低透明石墨或纯石墨。
- 暗色主题继续保留深石墨层次，不受浅色主题调整破坏。

## 3. 范围边界

本次只修改主题 token、共享页面样式、构建产物和设计索引。不修改 Vue 业务状态、REST、WebSocket、Session、RBAC、Channel、RuntimeEvent 或 AgentLoop 语义。

## 4. 模块设计

### 4.1 浅色主题

- 主阅读区：`#fcfbf7`，保留极弱暖感但视觉上接近白色。
- 设置和后台内容面：约 `#f9f8f4`。
- 侧栏玻璃：约 `#f3f3ef`，避免大面积米黄。
- 当前项与选中态：约 `#e3dfd1`。
- 正文与主操作：`#5c6a72` 灰蓝石墨。
- 链接和焦点继续使用同一灰蓝石墨体系，不引入品牌蓝。

### 4.2 登录页

浅色模式的品牌面板使用 `#6c787c` 到 `#aaaca4` 的雾灰渐变，表单面板从近白暖灰过渡到更浅的青绿 `#e2e9cb`，主按钮为 `#5c6a72`。深色模式继续使用原深石墨渐变，通过主题 token 切换，不建立第二套组件。

标准聊天侧栏宽度为 `280px`，紧凑密度为 `260px`，接近 GPT 等桌面聊天产品的导航比例；设置中心使用 `240px` 导航列，管理后台使用 `248px` 导航列，避免图标、标题、搜索框和三点菜单相互挤压。

个性化设置不再暴露“聊天内容宽度”。消息正文统一使用稳定的标准阅读宽度，删除 `uiStore.contentWidth`、本地存储和 `width-wide` 样式分支，避免用户把阅读列宽与 Session 侧栏宽度混淆。

### 4.3 跨页面一致性

Session 侧栏、账号区、设置导航和管理后台结构面共用浅灰玻璃语义。管理后台概览 Hero 在浅色模式不再使用大面积黑色，暗色模式仍保留深色层次。

## 6. 测试方案

- 运行前端 lint、typecheck、Vitest 和 production build。
- 在真实 Gateway 中分别检查浅色登录、聊天、设置和管理后台。
- 检查暗色主题仍可切换，文字和交互控件对比度可读。
- 检查页面无新增横向溢出，现有 Session 与聊天交互不回归。

## 7. 验收标准

1. 浅色模式不存在纯黑结构面，也不退回纯白冷灰。
2. 登录、聊天、设置和后台均表现为暖米白底、雾灰玻璃、灰蓝石墨强调。
3. 登录页保留确认截图中的浅青绿色环境光，产品面不出现品牌蓝。
4. 暗色曜石主题保持可用。
5. 所有前端静态检查、测试与 production build 通过。
