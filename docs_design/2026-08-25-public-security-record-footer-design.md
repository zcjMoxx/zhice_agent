# 公安备案页脚设计

> 说明：本文落地时把真实备案信息直接写入了前端源码；当前实现改由《2026-08-25 公安备案信息Private Runtime配置设计》使用private runtime配置和域名限制，本文正文中的真实值不再适用并将在隐私化迁移中清除。

## 背景

网站已取得公安联网备案号。备案平台要求在网页底部展示其下载的备案图标，并将备案号链接到公安备案查询页面。真实域名、编号与展示文案属于部署方私有配置，不写入仓库设计记录。

## 目标

- 在无需登录即可访问的认证页底部持续展示公安备案图标和备案号。
- 点击备案信息后在新窗口打开公安备案查询页面。
- 桌面、窄窗口和手机视口均不遮挡认证表单、不产生横向溢出。
- 使用备案平台下载的原始图标，不以文字或通用图标替代。

## 范围边界

- 覆盖登录、注册、Owner初始化和QQ绑定认证入口。
- 不在聊天、管理、旅游和工作流等登录后功能区重复展示，避免占用操作空间。
- 不引入外部图片请求、第三方脚本或运行时配置。

## 模块设计

备案信息直接作为 `AuthLayout` 的语义化 `footer`。链接固定使用公安备案查询地址，带 `target="_blank"` 与 `rel="noreferrer"`。备案图标作为Vite公共静态资源随前端产物发布，按20像素展示并保留原始比例。

认证页为备案区域预留底部空间；桌面端备案链接在视口底部居中，以轻量半透明表面保持各主题下可读。手机端将备案信息放入页面文档流：高屏自然位于卡片下方，矮屏可滚动到真正的页面底部，避免固定元素覆盖登录按钮；同时缩小外边距并保留安全区，不允许文本挤出视口。

## 数据流

1. Vite将公共目录中的备案图标复制到生产静态目录。
2. 认证布局渲染备案链接和图标。
3. 用户点击后由浏览器新窗口访问公安备案查询页。

## 测试方案

- 组件测试校验备案文本、公安查询URL、`target`、`rel`和图标地址。
- 前端lint、typecheck、全量测试和生产build。
- 检查生产产物包含备案图标，并在手机与窄桌面视口验证底部布局及链接可点击。

## 验收标准

- 未登录打开网站即可在页面底部看到官方图标和完整备案号。
- 点击后打开备案号对应的公安查询页面。
- 320像素宽手机视口无横向滚动，备案信息不遮挡表单按钮。
- 生产构建包含备案图标且所有前端质量门禁通过。
