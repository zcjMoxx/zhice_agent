# 2026-08-25 手机工作流画布交互设计

## 背景

8 月 24 日的响应式改造解决了工作流页面横向溢出和按钮挤压，但真实手机验收发现两个交互缺陷：只有 `min-height` 的画布令 Vue Flow 内层高度解析为零，节点被裁掉；改用固定 480px 高度后又造成编辑界面整体纵向滚动，拖动画布的手势容易与外层滚动冲突。手机端还继承了桌面的 420px 最小画布列宽，390px viewport 会裁掉右侧内容。

## 目标

- 进入流程画布后立即看到至少一个真实节点。
- 拖动画布空白网格只平移 Vue Flow，不带动整个编辑界面上下滚动。
- 390px 和 447px 手机 viewport 均不裁切画布容器，也不产生文档级横向滚动。
- 压缩操作区和配置提示占用，为画布保留尽可能大的可操作区域。
- 连接点在移动端始终可辨识、可触控，点选源节点后允许平移寻找目标，只有明确取消才退出连线模式。
- PC 端支持 `Alt + 滚轮` 强制横向移动画布。

## 范围边界

- 调整工作流移动端布局、点击连线交互和响应式契约测试，不改变节点数据结构、保存、发布或执行语义。
- 节点仍可超出当前画布视区，移动端通过拖动空白网格查看，桌面端另支持滚轮、`Alt + 滚轮` 和方向按钮。
- 执行记录继续使用自身纵向滚动，不强制采用固定画布布局。

## 模块设计

- `workflow-editor-results` 继续以 viewport 剩余高度为边界，编辑工具栏占自动高度，`workflow-body` 占满其余空间。
- `workflow-body` 在手机端恢复为两行 CSS Grid：横向步骤栏 + `minmax(0, 1fr)` 画布；同时覆盖桌面 420px 最小列宽。
- 画布使用 `height: auto; min-height: 0`，由 Grid 明确分配实际高度，使 Vue Flow 的 `height: 100%` 有可解析的父级高度。
- 编辑操作按钮改为单行横向滚动，避免四个操作按钮换成两行。
- 配置问题在移动端收进工具栏的“待配置 N”按钮，按需打开底部面板；问题长文本不再常驻遮住画布。
- 节点详情在手机端限制为约 42dvh 的底部面板并内部滚动；开始平移 viewport 时自动收起，避免已打开详情持续遮住可拖动网格。
- 手机端隐藏四个方向平移按钮，只保留撤销、重做和自动布局；配置提示背景不截获画布拖动，具体问题按钮仍可点击。
- 手机端隐藏占据大块画布的 Vue Flow 缩略图；缩略图看似空白但会截获鼠标事件，移除后把点阵区域完整交还给主画布拖动。
- Vue Flow 图层在手机断点显式使用 `touch-action: none` 和 `overscroll-behavior: contain`，并启用布尔 `pan-on-drag`；浏览器设备仿真把鼠标转换为触控指针时，手势仍由画布接管。
- 移动端连接点使用大于视觉圆点的 56px CSS 命中区域（在默认缩放后约 40px），并用更高优先级规则保证进入连线模式后不被桌面高亮尺寸覆盖；输出点常显，目标节点和输入点在连线模式下高亮。
- 连线中点操作按钮在移动端默认隐藏，仅选中连线后显示并向下偏移，避免遮挡相邻节点连接点。
- 点击源连接点进入持久的两次点击连线状态：点击目标节点完成，拖动或点击空白画布不退出，工具栏取消按钮、再次点击源连接点或 `Esc` 明确退出。
- 移动端不常驻操作帮助卡；桌面提示滚轮平移和 `Alt + 滚轮` 横移，避免继续显示手机不存在或当前实现不支持的组合键。`Alt + 滚轮` 在画布捕获阶段执行并阻止事件继续进入 Vue Flow，确保只改变横向视口而不串成纵向平移。
- 外层编辑区和 `workflow-body` 禁止纵向滚动，空白网格拖动事件由 Vue Flow 独占。

## 数据流

新增仅存在于编辑器内存中的配置面板展开状态与点击连线源节点状态。连线成功后仍写入现有 `edges`，失败继续走现有连接校验；不改变保存协议或后端数据结构。PC 的 `Alt + wheel` 只读取并更新 Vue Flow viewport。

## 测试方案

- 响应式契约测试锁定手机 Grid 列宽、画布剩余高度、单行工具栏、按需配置面板和触控连接点。
- 页面测试覆盖空白点击/平移不取消连线、目标节点点击完成连线、明确取消、配置面板开关和 PC `Alt + wheel` 事件拦截。
- 执行工作流相关测试、前端全量测试、typecheck、lint 和生产 build。
- 真实浏览器分别使用 390×844 与 447×800 viewport，测量编辑器、画布、Vue Flow 和文档尺寸。
- 在画布空白网格执行真实指针拖动，确认节点屏幕坐标随 viewport 平移而变化，外层页面位置保持不变。

## 验收标准

- Vue Flow 高度大于零，首个节点进入 viewport 后真实绘制且可点击。
- 文档高度等于 viewport 高度，编辑界面没有整体纵向滚动。
- 拖动空白网格后节点屏幕坐标发生变化，证明画布可平移。
- 390px viewport 下画布宽度不超过可用内容宽度，文档无横向溢出。
- 连线模式下平移画布后状态仍保持；点击目标节点成功生成边，明确取消后才退出。
- PC 端 `Alt + wheel` 后 viewport 的横向坐标变化，纵向坐标与缩放保持不变。
