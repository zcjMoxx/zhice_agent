# 工作流显式节点连线设计

## 背景

当前画布依赖 Vue Flow 的小型连接端口。端口缺少文字入口，已有连线删除或断开后，普通用户很难发现如何重新连接节点，也无法在操作前判断哪些节点可以作为下一步。

## 目标

- 每个节点直接提供中文“连接下一步”操作。
- 条件节点分别提供“是”和“否”分支连接操作。
- 进入连接状态后高亮可选的下一步，点击目标节点即可完成连线。
- 点击画布空白处或按 `Esc` 取消连接。
- 在前端即时阻止自连接、重复连接、重复占用条件分支、连接到开始节点和形成循环。
- 保留端口拖拽连接，兼顾熟悉画布操作的用户。

## 范围边界

本次只调整工作流画布的连线交互与前端校验，不改变工作流运行时、节点协议、权限或调度逻辑。不会自动执行、发布或发送任何外部消息。

## 模块设计

### 连接规则

`workflow-editor.ts` 提供无界面的连接校验函数，统一服务于按钮连接和拖拽连接。校验返回稳定的原因码，由页面转换为中文用户提示。

### 两步式连接

1. 用户在普通节点点“连接下一步”，或在条件节点点“连接 是/否”。
2. 画布显示“请选择要连接的下一步”，合法目标高亮。
3. 用户点击目标节点后创建连线；点击空白处或按 `Esc` 取消。

### 可发现性

节点连接按钮始终可见。底层拖拽端口在节点悬停、选中或连接状态下增大并增强颜色，作为快捷操作继续保留。

## 数据流

```text
点击连接按钮 -> 保存来源节点和分支 -> 计算合法目标 -> 点击目标
              -> 前端校验 -> 写入 edge -> 记录撤销历史 -> 退出连接状态
```

序列化时，条件节点的 `true/false` 只写入 `condition_branch`，协议端口仍写为 `output -> input`，与后端工作流校验规则一致。

## 测试方案

- 单元测试覆盖合法连接、自连接、重复连接、条件分支占用、开始节点作为目标以及循环连接。
- 页面测试覆盖进入连接状态、点击目标完成连接、条件分支保留和空白画布取消。
- 运行前端 lint、类型检查、完整测试与生产构建。

## 验收标准

- 用户不需要理解端口即可重新连接两个已有节点。
- 连接状态和取消方式清晰可见。
- 非法连接不会写入画布，并显示可理解的原因。
- 条件分支语义在保存定义中保持正确。
- 原有拖拽连接、加节点、删线和撤销能力不回退。
