# 纯文本展示适配测试说明

## 测试目标

验证共享 Markdown-to-plain renderer 在不支持 Markdown 的 CLI 与外部渠道中保留可读信息结构，同时不修改 Session 原始内容，也不依赖具体客户端或 SDK。

## 正常路径

- 标题、强调、删除线和行内代码保留正文。
- 无序、有序和任务列表转换为稳定纯文本标记。
- 链接、图片、引用、代码块和表格保留关键信息。

## 异常路径

- 未闭合 fenced code 不丢失代码正文。
- 不完整或未知 Markdown 原样保留可读内容。

## 边界路径

- 空文本返回空文本。
- 普通纯文本保持幂等。
- Windows 换行被规范化，连续空行被收敛。
- `<绑定码>` 等非 HTML 占位符不被误删。
