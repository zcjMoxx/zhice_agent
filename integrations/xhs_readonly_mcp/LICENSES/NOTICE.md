# Upstream attribution

This read-only catalog adapter is designed to interoperate with the community
project `xpzouying/xiaohongshu-mcp`:

- Upstream: https://github.com/xpzouying/xiaohongshu-mcp
- Upstream license: Apache License 2.0
- License snapshot: `xpzouying-xiaohongshu-mcp-APACHE-2.0.txt`

ZhiCe-Agent does not vendor the upstream executable or its source code here.
The adapter exposes only login status, search, and detail operations. Publishing,
commenting, liking, collecting, deleting, and other write operations are absent
from this MCP Server catalog.
